OPTICAL DATA SUMMARY // 實測光學數據對照

改變透視關係的從來是你的雙腳，焦段負責決定取景框的裁切比例。

在光學物理上，只要拍攝者與被攝者的站位不變，無論換上 16mm 或 200mm，前景與背景的透視比例完全相同。之所以產生「廣角誇張、長焦壓縮」的強烈反差，是因為我們為了讓人物在畫面裡維持同樣的半身大小，被迫往前走近 50 公分，或是往後退開 6 公尺。

CONCLUSION 01 // 距離與親密感

想拍出臨場呼吸感，選 35mm 走進現場

當你站在距離被攝者 1.2 公尺的社交距離內，對方的眼神交流與肢體動作最自然；畫面同時保留當下的餐桌、街道與光影線索。

CONCLUSION 02 // 雜亂背景救星

台灣街頭招牌太亂？換 85mm 以上的窄視角

與其靠大光圈硬把背景糊掉，不如退後兩步換上 85mm 或 200mm。視角從 63° 縮窄到 12°，只要稍微移動半步，就能把背後的垃圾桶與電箱徹底移出取景框。

CONCLUSION 03 // 視覺重量控制

要氣勢用 16mm 貼近，要壓迫感用 200mm 遠攝

廣角仰拍能讓一棟三層樓老宅看起來像摩天大樓；而長焦遠攝則能讓遠處的山嵐或夕陽塞滿整個取景窗，產生無法逃離的宿命感。
