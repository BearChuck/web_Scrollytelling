PHASE 01 — 16mm VENUE & CROWD FOV 107°

壓軸大合照與爆滿氣勢

千人論壇最後的大合照，台下第一排離舞台邊緣往往不到 2 公尺。退無可退時，16mm 的 107° 超廣視角能一口氣吞下整面 12 公尺寬的主視覺 LED 牆與全場舉起手機的觀眾；就算是 50 人的小型講座，蹲在走道低角度仰拍，也能靠廣角拉伸感交出「全場爆滿」的公關照。

站位：舞台前緣 / 制高點 注意：人物勿放畫面最邊緣
PHASE 02 — 35mm NETWORKING & BOOTH FOV 63°

茶敘敬酒與展攤互動跟拍

中場休息的 VIP 交流區與簽到背板前，通道擠滿端著香檳的來賓，根本退不到兩公尺外。掛上 35mm 站在 1.2 公尺社交距離抓拍，既能清楚拍下貴賓交換名片、碰杯大笑的表情，又能把背後的贊助商 Logo 與展攤陳設完整帶入，交代現場故事脈絡。

站位：報到櫃檯 / 展攤走道 (1.2m) 敘事平衡：人景五五開
PHASE 03 — 85mm KEYNOTE & VIP FOV 28.5°

講者眼神特寫與雜物剝離

活動會場到處是破壞畫面的礦泉水瓶、麥克風線、逃生指示燈與發呆的工作人員。退到 3 公尺外換上 85mm f/1.4，28.5° 窄視角加上淺景深，能瞬間把講者身後的雜亂背景融化為柔和光斑，精準鎖定主講人比手勢的瞬間與台下 VIP 專注點頭的側臉。

站位：舞台側翼 / 第一排走道 (3m) 主體分離度：極高
PHASE 04 — 200mm STAGE COMPRESSION FOV 12°

遠距零干擾狙擊與滿版背板壓縮

頒獎典禮或啟動儀式時，你不能衝上台擋住台下長官與轉播攝影機的視線。站在 10 公尺外的中場走道端起 200mm，僅 12° 視角能越過前排黑壓壓的後腦勺，把原本離講者 4 公尺遠的舞台 LED 主視覺硬生生拉近貼滿整個背景，連得獎者眼眶泛淚的瞬間都無所遁形。

站位：中後排走道 / 音控台旁 (10m+) 空間壓縮感：背板滿版貼合
EVENT COVERAGE OPTICS // 活動攝影雙機流與焦段數據對照

活動現場沒時間讓你慢慢換鏡頭，站位距離決定你的畫面說服力。

在光學物理上，透視關係只取決於你與被攝者的距離。當主講人突然與台下第一排貴賓握手、緊接著退回舞台中央致詞，流程往往只有短短 5 秒鐘。理解 16mm 到 200mm 的視角裁切與背景壓縮特性，你才能預判該「往前衝進人群」還是「退後靠長焦壓縮背板」，張張都是公關發稿直接能用的黃金畫面。

FIELD TIP 01 // 經典雙機流配置

左肩 16-35mm 搶大景，右肩 70-200mm 抓特寫

活動攝影師最怕錯失瞬間。左機掛廣角應付突如其來的貴賓合照與狹窄走道跟拍；右機掛長焦隨時狙擊舞台上的講者手勢與台下大笑，不換鏡才能全場零漏網。

FIELD TIP 02 // 拯救凌亂會場

場地布置太簡陋？退後換 85mm 切乾淨

遇到小型會議室白牆、外露線材或便當盒堆在角落時，千萬別硬用廣角。退後兩步換上 85mm 或拉到 200mm，把視角縮窄到 28° 以內，畫面只留講者與乾淨的局部背板。

FIELD TIP 03 // 公關發稿必備視覺

人少用 200mm 壓出擁擠感，人多用 16mm 拍氣勢

當台下座位沒坐滿時，從第一排斜側面用 200mm 貼著前排觀眾肩膀拍向講者，長焦壓縮會讓前後三排觀眾看起來像座無虛席；全場滿座時再站上高處用 16mm 一網打盡。
